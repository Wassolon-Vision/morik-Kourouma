# HAMAC SERVICES – Comptes clients (versements et retraits)

Application web installable sur téléphone. Les données restent sur l'appareil.

## Fichiers à déposer sur GitHub (tous, à la racine du dépôt)
index.html, manifest.json, sw.js, logo.png, favicon.png, icon-192.png, icon-512.png, README.md

## Mise en ligne (GitHub Pages)
1. Sur github.com, créez un dépôt (ex. `hamac-services`), de préférence en privé.
2. « Add file » > « Upload files », déposez tous les fichiers ci-dessus, puis « Commit changes ».
3. Settings > Pages > « Deploy from a branch », branche `main`, dossier `/ (root)`, Save.
4. Après 1 à 2 minutes : `https://VOTRE-NOM.github.io/hamac-services/`

## Installation sur le téléphone
- Android (Chrome) : ouvrez l'adresse, menu ⋮ > « Installer l'application » ou « Ajouter à l'écran d'accueil ».
- iPhone (Safari) : bouton Partager > « Sur l'écran d'accueil ».

## Important
- Faites une sauvegarde JSON chaque semaine (Paramètres > Données).
- Ne mettez jamais de vraies données clients dans le dépôt GitHub.
